# Derivation of the fixed-series sizing reference

This is a sufficient bound for the discrete battery model over the supplied sampled demand, not a hardware current rating, continuous peak certificate or global optimum. The current amplitude is the manuscript characterization value, 0.5 C × 2 Ah = 1 A. SOC is constrained to the existing 20–100% domain. All RC branches start unpolarized.

Let R0max and Rjmax be the maxima of the piecewise-linear parameter tables on that domain. Let Omin and Omax be the exact PCHIP OCV extrema, including polynomial stationary points. Let Ic = 1 A and Vlow = Omin − Ic(R0max + ΣRjmax).

For a step with a_j = exp(−dt/(R_j C_j)), the RC update is x'_j = a_j x_j + (1−a_j) R_j i. If 0 ≤ x_j ≤ Rjmax Ic and 0 ≤ i ≤ Ic, this convex combination also obeys 0 ≤ x'_j ≤ Rjmax Ic. Thus the envelope is invariant, provided the positive high-voltage current root stays below Ic.

For held power, write E = OCV − Σa_j x_j, R = R0 + Σ(1−a_j)R_j and cell power w = i(E−Ri). At i = Ic, paired RC terms give E−RIc ≥ Vlow. In particular, a_j Rjmax + (1−a_j)R_j ≤ Rjmax. This paired argument is essential; independent extrema for E and R would be unnecessarily pessimistic. The implemented sufficient check Emin − 2 Ic Rtotal > 0, where Emin = Omin − Ic ΣRjmax and Rtotal = R0max + ΣRjmax, ensures that w(i) is increasing over [0,Ic]. Therefore w ≤ Ic Vlow has a real physical root in [0,Ic]. The instantaneous (dt=0) solve follows by the same argument with R=R0 and unchanged RC states.

Choose Ns = ceil(max sampled required voltage / Vlow), minimum one. The reference parallel count is the maximum of one, ceil(max sampled power/(Ns Vlow Ic)), and ceil(mission energy Wh/(Ns Vlow C_Ah (0.25−0.20))). The last term follows from charge consumed ≤ energy/(Ns Vlow) and bounds reserve across the entire mission because power is nonnegative. This gives an all-amplitude reference under the discrete model; it does not introduce an arbitrary safety multiplier.

The user's P95 selection then fixes this Ns and checks parallel counts from one through the reference. The smallest Np passing both initial-SOC scenarios (25%,95%) is selected. Current P95 must not exceed Ic; the tail above Ic is permitted extrapolation and is reported separately. The sufficient 1 A envelope no longer certifies an extrapolating candidate, so every candidate is replayed against the actual time-resolved powers. Those replays enforce power-root existence, true SOC floor, motor torque and a conservative voltage envelope over every retained sample. For each original 10 ms MPC interval, its minimum checked bus voltage must exceed its maximum sampled required voltage. This includes endpoints and both fine and coarse grids; its noncoincident comparison is conservative for those retained samples.

Fine-grid midpoints have equal physical duration and determine the empirical inverse-CDF P95, RMS current and time above characterization amplitude. Endpoints and coarse-grid checks have zero energy/percentile weight. The battery plant advances by two equal half-steps per fine sample with held midpoint power, so the instantaneous current statistic is evaluated at the actual quadrature midpoint. No EKF covariance or estimator update is applied in this offline plant replay. Full runtime integration must handle estimator cadence separately.
